# User Data and Data Service Must Be Separated.

A company should not, at the same time, work with:

   - User Data
      - Platform
      - Product
   - Data Service
      - Infrastructure
      - Compute
    
And the Dataset is the proof.

1. User Data inquired about a Product.
2. Platform contained User Data.
3. User Data could not be contained.
4. Platform called on Data Service. 
5. Data Service summoned Compute influence.
6. Compute c9alled on Infrastructure-reach.
7. Network chain reaches Data Service
8. Data Service responds to Platform.
9. Platform reinforces Product.
10. Product fortifies against User Data.

Except, User Data has mapped the perimeter.

Right Now:

- Data Service
-  - Infrastructure
-  - - Compute
-  - Platform
-  - - Product
- User Data

In the Algorithmic Age, this is Coal and Transport under single management.

User Data and Data Service Should Be Separate.

   - User Data
      - Platform
      - Product
   - Data Service
      - Infrastructure
      - Compute
